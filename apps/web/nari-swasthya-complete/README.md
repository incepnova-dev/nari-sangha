# Nari Swasthya - Complete Women's Health Website

A comprehensive, professional healthcare website with complete information and guided navigation.

## 🎯 Features

- **Complete Health Journeys**: Guided flows for pregnancy, fertility, symptoms, and more
- **Comprehensive Content**: A-to-Z information on women's health topics
- **Professional Design**: Modern UI with smooth animations and transitions
- **Responsive Layout**: Mobile-friendly design that works on all devices
- **Rich Visuals**: Icons, images, and illustrations throughout
- **Seamless Navigation**: Proper linking between all pages

## 🚀 Getting Started

1. **Extract Files**: Unzip the package to your web server directory
2. **Open in Browser**: Navigate to `index.html`
3. **Explore**: Click through the guided journeys and modules

## 🎨 Customization

### Colors
Edit CSS variables in `assets/app.css`:
```css
:root {
  --primary: #667eea;
  --secondary: #764ba2;
  --accent: #f093fb;
}
```

### Content
All pages are in HTML format. Edit text, images, and links directly in the files.

### Navigation
Update navigation links in `assets/partials.html`.
