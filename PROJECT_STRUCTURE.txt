Important Configs
- Root: package.json (workspaces), start-all.sh (orchestration).
- API: .env.example (not committed but referenced), tsconfig.json, jest.config.js, prisma/schema.prisma.
- Web: .env (user-provided), tsconfig.json, config-overrides.js, API_INTEGRATION.md, api.config.ts.
- Mobile: app.json, tsconfig.json, babel.config.js, metro.config.js, react-native.config.js, android/build.gradle, android/gradle.properties.
- Shared: packages/api-client/tsconfig.json, package.json.

Scripts (key)
- Root: npm run build:api-client; npm run watch:api-client; start-all.sh.
- API: npm run dev; build; start; prisma:generate; prisma:migrate; prisma:studio; db:setup; db:seed; test; test:watch; test:coverage; scripts/generate-jwt-secret.sh; scripts/setup-database.sh; scripts/seed-database.ts.
- Web: npm start; build; test; eject.
- Mobile: npm start (Metro); npm run android; npm test; npm run lint; android/gradlew tasks (assembleRelease, test); scripts/generate-test-summary.sh.
